## Configuration and discovery

GPT configuration is at [its executable declaration](../src/api_agent/llm_providers/gpt/cfg/config.toml). GPT_STATE_DIR is a hidden advanced override; empty uses the protected per-user location. There is no GPT_PROFILE setting. Without a vault descriptor, exactly one cached OAuth connection may be reused; attended OAuth identifies the user when the cache is empty/ambiguous. A configured optional LLM User descriptor binds unattended reuse to its retrieved username. No unique matching connection requires attended sign-in, without another browser/account fallback. Unattended login-page automation remains pending.

Factory creation, help, collection and test selection do not authenticate. Integration tests explicitly request setup when needed. Recorded execution requires interactive Start and Allure storage configuration; collection-only does not start setup or storage. E2E execution and its mandatory human acceptance remain separate work.
