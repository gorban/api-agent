No other test runs between these confirmations. Do not apply reruns to unit tests.
  - [ ] Preserve the initial outcome and each confirmation outcome in TUI/Allure reporting. A test is finally passed only on its first pass or both successful confirmations. With reruns disabled, omit the final-passing statistic from the suite summary. Cover the protocol with deterministic unit tests before using it for "Ok".
  - [ ] Include whole-suite prompt counts, usage/cost, and the [mode-specific final summary](implementation_plan_a.md) from the first "Ok" run, including all confirmation attempts.
