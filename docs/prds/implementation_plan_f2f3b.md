The defect is client liveness: the shared application lifecycle already applies its thirty-second heartbeat expiry to buffered chat requests. The comparison previously sent no heartbeats, so a valid inference lasting longer than that lease could be cancelled before token scoring. This repair honors the established lifecycle contract; it does not alter expiry or make the stochastic token-gap threshold reliable. The separate [reasoning stability follow-up](implementation_plan_f2f3a.md) remains deferred.
