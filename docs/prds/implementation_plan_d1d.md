# Allure link interaction and CDP clarity

[Allure viewers](implementation_plan_d1.md) · [Selected-test navigation](implementation_plan_d1a.md)

- [x] Render report/archive URLs as explicit whole links in both wrapped notifications and the history page. Every wrapped segment retains the complete destination and common hover identity; do not rely on terminal URL detection. Keep URLs and error text literal rather than interpreting their contents as markup/actions.
- [x] Clicking a report/archive link explicitly copies the complete URL and requests normal external opening. Explain that action in the visible label. Clipboard failure must not block opening; opener failure retains an actionable copy/manual-open fallback. Because a terminal driver may discard opener failure status, post-click copy feedback explains how to paste/open manually without claiming the browser opened. Rendering, hover, test completion and ordinary navigation must never copy automatically.
- [x] Label the browser address as CDP for automation, not a web page. Its explicit click action copies the connection base without opening the empty root. Explain that `/json/version` returns discovery metadata; retain the base address used for Playwright/DevTools attachment. Do not replace the report address with the CDP address or alter managed browser lifetime.
- [x] Verify actual narrow/wide Textual rendering, common hover identity and clicks on later wrapped lines, complete URL clipboard/open arguments, copy-only CDP, archive links, literal markup-like text, independent clipboard/opener failures including a False result through the actual terminal driver, and no unsolicited clipboard writes. Use controlled clipboard/open adapters; preserve current test/browser/cleanup ownership.
- [x] Complete applicable exact coverage, installed/package/license and public-boundary/index/metadata checks, plus independent review. No paid inference or real clipboard writes are needed for deterministic verification.
- [ ] Human-review wrapped URL hover/click/copy, CDP labelling and manual-open fallback in the terminal used for development.
