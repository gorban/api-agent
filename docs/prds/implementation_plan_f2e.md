# Partitioned credential protection

Registered authentication and recognizable Bearer credentials must not become recoverable by concatenating assistant text parts or enabled evidence arrays. This extends the [native metadata contract](implementation_plan_f2d.md) without changing ordinary text, tool execution, usage or opaque replay.

## Requirements

- [x] Registered-token protection also detects invisible-character insertions in decoded serialized text, including split strings, object keys/values and ordered arrays. Detection retains original ranges; harmless controls and functional results remain unchanged. Independent provider, IPC, parent-export and recording controls must detect removal of this guard.
- [x] Validate combined assistant output before returning successful GPT tool inference through JSON or subscription SSE. Credential-bearing output fails safely while preserving available usage and execution status.
- [x] Generic emission boundaries redact registered and recognizable Bearer credentials spanning ordered string arrays both before and after recursive sanitization/canonicalization, including backend content export and parent attachment export. Keep ordinary split text intact; default-off content remains disabled.

- [x] Focused mutation controls detect removal of each combined-text protection; [synthetic regressions](../../tests/unit/test_partitioned_credentials.py) cover provider and export boundaries independently.
- [x] Independent source review closes the serialized-partition, concealed-scheme, range-union and duplicate-key extension.
- [x] The full repository unit gate completes for the current extension. Earlier recognizable-credential qualification remains historical evidence.

- [x] Apply serialized-JSON decoding recursively through strings, objects, arrays, scalar values and credential-bearing object keys to combined raw and recursively sanitized text, so escaped registered and Bearer credentials cannot bypass the whole-text policy. Share normalized registered-JSON representation comparison with contiguous emission, covering whitespace/escaping changes to object, array, quoted-string and scalar credentials. Preserve ordinary split JSON and exact execution results; test backend serialized IPC frames before parent export and recording. [Serialized-partition regressions](../../tests/unit/test_partitioned_json_privacy.py) cover independent constructed results, mocked JSON/SSE, default-off controls and recorded attachments.

Union registered, literal-syntax and detection-view ranges from original text before redaction; neither registration-first nor syntax-first replacement may conceal the other credential. Actual backend frames and recording cover independently registered collisions, split and nested JSON, and parent boundaries without the registered value.

Only synthetic credentials, local owned IPC and mocked HTTP are needed. These requirements authorize no live inference or change to statistical calibration evidence.
