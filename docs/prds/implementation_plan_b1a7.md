# Interactive diagram overlay

[Workflow resources and views](implementation_plan_b1a.md) · [Managed lifetime](implementation_plan_b1a6.md)

- [ ] Load one shared, local presentation enhancement in saved workflow documents, including ordinary `file://` opening after locked frontend preparation, and in managed viewing. An ordinary click on a vetted linked SVG opens an accessible overlay without first navigating to the standalone SVG. Fit the complete diagram to the limiting width or height while preserving aspect ratio; refit on viewport changes while retaining relative zoom.
- [ ] Provide labeled Zoom in, Zoom out, Fit and Close controls with bounded zoom and scrollable overflow. Support keyboard activation, Escape, focus containment/restoration and backdrop dismissal. Keep controls usable for wide, tall and narrow viewports. Unsupported browser APIs preserve standalone navigation.
- [ ] Keep SVG links interactive. Declaration, fragment, schema and configuration links reach their destinations directly from the overlay. Preserve modified-click/new-tab behavior. In managed viewing another admitted SVG can replace the diagram. Respect ordinary file-origin isolation without insecure browser flags or arbitrary file reads.
- [ ] Share canonical authored assets between static and managed viewing; prepare/package their exact bytes through the existing finite asset inventories. Permit only the narrow frame/resource policy needed for local diagrams. Preserve styles, forbid arbitrary remote SVG loading and retain existing script restrictions. Rendering must leave extracted executable declarations, selected graph behavior and model/settings unchanged.
- [ ] Retain and test the managed server's bounded decoration seam and captured SVG route admission. Capture before listening; do not broaden filesystem access. Later execution/history overlays remain separately planned in the [inspector requirements](implementation_plan_b1c.md), with no runtime observations embedded into static sources.
- [ ] Show useful loading/failure feedback. Closing or replacing disposes pending work, frame/document listeners and resize observation; late results cannot resurrect a closed overlay. Viewing requires no graph execution, authentication or application startup.
- [ ] Verify real ordinary-file and managed browser behavior for root/nested declarations, limiting-axis fit, zoom/refit/scroll, controls/focus/Escape, direct links, unavailable content and disposal, with causal controls. Renew applicable exact unit line/branch coverage, installed/relocated assets, notices, source/index/metadata and independent/external reviews before delivery. Independently review any presentation-only qualification source rebinding while preserving original observations; execution or model/settings changes retain their separate qualification gate.
- [ ] Human acceptance of fitted interactive navigation in static and managed viewing. Combined D5 acceptance remains separate.
