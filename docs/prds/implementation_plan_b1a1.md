# Portable static documents and markup freshness

[Workflow resources and viewer](implementation_plan_b1a.md) · [Staged checks](implementation_plan_i1a.md)

- [ ] Support direct browser opening of root and nested `.md.html` without a server or network dependency. Use an exact versioned presentation envelope around inert executable Markdown; reject arbitrary HTML/scripts. Preserve readable declarations, root-only fallback help and specified IDE comments. Bundle the licensed Markdown/sanitization scripts and their notices. Hosted augmentation cannot change execution semantics.
- [ ] Keep SVGs external under the owning `.private_resources/diagrams/` tree, with companion Markdown for repository-hosted navigation. Use best-effort common platform/free font-family fallbacks inside SVGs and document styles. Bundle or download no fonts and require no container toolchain. Static viewing needs no Java/PlantUML; geometry and glyph appearance may differ by platform.
- [ ] Define freshness against the admitted canonical markup and selected declaration/resource closure, plus projected PlantUML and pinned generator/options provenance. Exclude only the versioned presentation envelope and generated navigation section; bind presentation assets separately and avoid circular self-hashes. Compare the embedded projected source and input hashes to the current projection. Never require equality with locally regenerated SVG geometry.
- [ ] Check actual saved SVG bytes for bounded safe vocabulary, links and geometry, and verify their recorded graphic digest. This detects corruption separately from markup freshness; a self-declared digest is not an independent signature or proof of drawing fidelity. Compare generated HTML, companion links and viewer assets with their expected deterministic content.
- [ ] Managed viewer preflight and explicit/staged check commands validate the selected saved snapshot without Java, renderer lookup, downloads or graph/provider execution. Missing, unsafe, corrupt or source-stale output fails with generation guidance. Direct `file://` opening displays the last generated artifact; it does not run the Python freshness check.
- [ ] Use the pinned optional PlantUML generator only during explicit generation or when a managed selected variant needs a new temporary diagram. Dispose owned processes/temporary files on success, failure and cancellation. Explicit source generation leaves corrections unstaged and preserves concurrent edits. Ordinary agent execution requires no generator, viewer or hook installation.
- [ ] Keep owner-local static artifacts separate from managed library/replacement variants. Derive temporary views from admitted selected inputs, disclose graph/definition identity and bind diagrams to that markup. Never overwrite owner diagrams, reload unselected originals or substitute a different graph. Preserve source and installed files unchanged while viewing.
- [ ] Require explicit per-path confirmation before removing obsolete generated outputs. Markers and self-computed hashes cannot establish deletion ownership; preserve unknown or edited files.
- [ ] Prove fresh checks work without Java; alternate safe font geometry does not become stale; changed declarations, linked resources, projected-source metadata or companion links reject. Reject unsafe SVG even with a recomputed digest and reject damaged graphics without a matching digest. Verify static/hosted root/nested and relocated-wheel navigation, parser equivalence and original managed-browser cleanup before combined human acceptance.
