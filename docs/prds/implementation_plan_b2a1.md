## Requirements

- [x] Layout v1 object contracts use JSON Schema draft 2020-12. Omitted `$schema` means this dialect; the explicit canonical URI is accepted. The same rule applies recursively at draft 2020-12 schema/subschema positions, including embedded resources with their own `$id`, deprecated `definitions`, and schema-valued `dependencies` recognized by the installed meta-schema. Dependency property-name arrays remain data. Instance data in `const`, `default`, `enum`, `examples` and custom annotations, and property names such as `$schema`, `$ref` and `$dynamicRef`, retain their ordinary meaning. Reference detection visits only these schema-valued positions: `$ref` and `$dynamicRef` within ordinary data or property-name maps do not reject the contract. Actual schema references reject before function and inference effects, including recognized legacy schema positions. Other declared dialects fail with a source-located diagnostic before registered functions or inference execute. The fixed dialect matches the runtime validator and keeps the restricted contract independent of external schema retrieval.
- [x] Read each distinct linked prompt file once at the start of each execution, before any node runs. Preserve declaration ordering and evaluate conditional inclusion against each node's current values. Retries reuse the same text; a later execution loads current files. Snapshots belong to execution state, so concurrent runs do not overwrite each other's prompts.
- [x] Executable links require inline Markdown syntax. Reference definitions in Notes cannot resolve or redirect executable table links. Full, collapsed and shortcut reference links, images and autolinks are rejected as executable links. Notes prose remains permitted and does not affect executable resolution.
- [x] Preserve source provenance, guard budgets, deadlines, cancellation, owned cleanup, observer diagnostics and original user input. Missing or unreadable prompts fail before node effects; failed executions do not become successful calibration evidence.
