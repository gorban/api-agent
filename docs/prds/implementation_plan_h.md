# Conditional infrastructure and host UI

Local API means the selected pack's upstream API; the api-agent chat API remains the shared application. Pack declarations supply concrete services and startup requirements. Disabled features and test collection start no services.

## Requirements groups

- [ ] Support [shared dotenv configuration layers](implementation_plan_h3.md) through normal bootstrap and configuration editing.

- [ ] Complete [prerequisite foundation and ownership](implementation_plan_h1.md): delivered controlled Compose/readiness/lease contracts, remaining asset collection and live operation wiring.
- [ ] Complete [application prerequisites, tracing and host UI wiring](implementation_plan_h1a.md): selectable profiles, pack-owned endpoints, host UI, logging, browser lifecycle and local-run onboarding.
- [ ] Implement [shared resource ownership, fixed ports and persistent coordination](implementation_plan_h2.md): durable reporting service, one cache per computer, safe cleanup and future resource coordination.

Existing foundation delivery remains recorded in the children. These grouping checkboxes stay open while implementation or independent review remains; they do not grant acceptance for live services, parallel suites or destructive lifecycle changes.
