Only an effective, explicitly supplied `True` from `.env`, environment, or CLI permits content logging; omission, a declaration/pack default, explicit `False`, unresolved configuration, or an invalid value must not enable it. Respect normal precedence and retain value-source provenance. Local testing may explicitly set `LOG_CONTENT=True`.
- [ ] Apply the same gate to application/child-process diagnostic logs, Langfuse, and every tracing/export path in both api-agent and selected resource packs. Treat all such content as potentially sensitive rather than attempting to recognize just known PII patterns.
