## Single-line .env example

```dotenv
UNATTENDED_AUTH='{"password_manager":{"manager":"keeper","cli_path":"/path/to/keeper"},"roles":{"LLM User":[{"vault":"my-vault","user":"LLM User"}]}}'
```

When a secondary role is enabled, include another array within roles under its declared label, using vault and user per entry. The shared manager serves all accounts. Empty arrays select the consuming provider or resource pack attended fallback. Multiple complete selectable indexes require an explicit zero-based index or an interactive choice. Resolve only the roles actually consumed by the operation; resource packs own UI authentication and API-provider extensions own upstream authentication.

## Exact retrieval commands

Keeper password (raw output):

```text
<path_to_keeper_cli> find-password '<vault>/<name>'
```

Keeper TOTP (raw output):

```text
<path_to_keeper_cli> clipboard-copy '<vault>/<name>' --totp --output stdout -t
```

1Password password (CSV-formatted single cell):

```text
<path_to_op_cli> item get '<name>' --vault '<vault>' --fields password --reveal
```

1Password TOTP (raw output):

```text
<path_to_op_cli> item get '<name>' --vault '<vault>' --otp
```
